# Feature Index

- `01-site-build.md` — Site Build: generates `site.out/` from `site.in/` (worked example).
- `02-project-pages.md` — Project Pages: the standard published page set (status, dashboard, condensed todo/prompts/documents).
- `03-language-core.md` — Language Core: Elseon's philosophy, the Kernel Test guarantees, the C/JavaScript syntax family, and the OOP lessons adopted.
- `04-c-header-ingestion.md` — C-Header Ingestion (PFE): C headers as first-class semantic modules.
- `05-llvm-backend.md` — LLVM Backend: code generation with deterministic memory layout.

- The bundled site-build feature is a worked example, not a requirement.
- The language features (`03`–`05`) are requirements: they define the
  Elseon design and the toolchain that must implement it.
