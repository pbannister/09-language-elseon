# README for documents

Human-consumption documents live here.

The LLM does not load these files as project rules.

## Index

- `00-pattern-of-interaction.md` — how to work with an LLM: work items, episodes, async, and review.
- `01-async-worktree.md` — worked example: run the LLM in its own git worktree and merge when the episode settles.
- `02-tool-universe.md` — a survey of LLM tools through the async and attention lens.
- `03-conversation-summary.md` — a summary of the conversation that produced these documents.
- `04-lessons-from-homelab.md` — lessons from the first real application of the skeleton.
- `05-lessons-from-MI25.md` — lessons from the MI25 fan-service project.
- `06-project-pages.md` — project-pages publishing conventions (summary; canonical version in the homelab).
- `07-elseon-language.md` — the Elseon language design: philosophy, the kernel test, syntax family, OOP lessons, and C-header ingestion.
- `08-related-work.md` — survey of prior attempts at an improved C, the exclusions (Rust, D), and the ideas Elseon borrows.
- `13-c3-vs-c.md` … `18-c-comparison-synthesis.md` — the episode 1-A C-comparison studies and their synthesis.
- `19-c2-vs-c3.md` — the C2-versus-C3 lineage study (C3 is documented as a fork of C2).
- `20-lessons-from-elsewhere.md` — human notes on lessons learned elsewhere.
- `21-c-compiler-extensions-inventory.md` — inventory of prior work on extending or modifying C compilers (research input).
- `22-fork-or-extend-decision.md` — fork-versus-extend decision record for the language base.
- `23-constructor-destructor-variants.md` — constructor and destructor invocation sites, overt versus hidden, with the design's per-site rulings.
- `24-scope-exit-mechanisms.md` — clause-level detail for four non-C++ scope-exit mechanisms (companion to 23).
